# Marvel Game

Marvel Game este un joc Web trivia educativ bazat pe eroi Marvel.

## Tehnologii folosite

- PHP 
- SQLite
- JavaScript
- HTML/CSS
- API-uri JSON prin fetch/Ajax

## Cum rulezi proiectul
php database\setup.php
php database\seed_translations.php
php database\seed_demo.php
php -S localhost:8000 -t public
